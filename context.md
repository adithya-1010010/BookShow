## MOVIE TICKET BOOKING SYSTEM

## Introduction

The system is designed to provide users with an easy and convenient way to browse available movies, select show timings, choose seats, and book movie tickets online. It helps reduce manual work and makes the ticket booking process faster and more efficient. The project demonstrates the use of Java programming concepts to create a simple, user-friendly, and organized booking system.

## ABSTRACT

- ·The Movie Ticket Booking System is a Java-based desktop application developed to simplify and automate the traditional movie ticket booking process.

## Objectives

- ·To automate the movie ticket booking process.
- ·To provide an easy and efficient ticket booking system.
- ·To allow users to view available movies.
- ·To manage theatres and show timings.
- ·To prevent duplicate seat bookings.

## MODULES

- ·Home Module - Provides the main page and navigation.
- ·Movie Module - Displays available movies, genres, and ticket prices.
- ·Booking Module - Allows users to enter customer details and select show timings.
- ·Ticket Module - Calculates the total ticket cost based on the number of tickets.
- ·Confirmation Module - Displays the booking ID and complete ticket details.
- ·OOP Module - Uses classes, objects, inheritance, and polymorphism in JavaScript
