# Glossary

- **Show** — a specific screening: one movie, at one theatre, at one date/time, on one screen.
- **Seat** — a bookable unit tied to a specific show (not to the theatre in general) — each show has its own independent seat availability.
- **Booking** — a confirmed reservation of one or more seats for one show by one customer, with a generated Booking ID.
- **Booking ID / booking_code** — human-facing unique identifier shown on confirmation.
- **PricingStrategy** — pluggable rule for computing per-seat price for a show.
- **DAO** — Data Access Object; hides SQL behind a Java interface.
- **Seed data** — initial fixed dataset inserted automatically on first run so the app is usable without an admin UI.
