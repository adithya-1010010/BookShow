# Objectives

Source: `context.md` (authoritative).

1. Automate the movie ticket booking process.
2. Provide an easy and efficient ticket booking system.
3. Allow users to view available movies.
4. Manage theatres and show timings.
5. Prevent duplicate seat bookings.
6. Demonstrate Java OOP concepts (class, object, inheritance, polymorphism) through a realistic application, not contrived examples.
7. Produce a maintainable, layered codebase appropriate for an academic project (not over-engineered).
