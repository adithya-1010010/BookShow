# Development Workflow

1. Read `docs/13-reference/memory.md` first, every session.
2. Implement exactly one phase (see `03-planning/implementation-plan.md`).
3. Test per `10-testing/test-plan.md`.
4. Update docs touched by the phase.
5. Update `memory.md`.
6. Commit + push (see `git-workflow.md`).
7. Stop.
